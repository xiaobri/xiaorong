# linear_focal_all

在全部 Train 抽样窗口上，用原项目 Focal（阳性 α=0.85，γ=2）监督零初始化的 195→1 线性残差。锁定学习率为 0.0001。原六专家核心使用基线完整损失。

| seed | 轮次 | 阈值 | F1 | Δ baseline |
| --- | ---: | ---: | ---: | ---: |
| 0 | 9 | 0.82 | 70.006 | +0.185 |
| 1 | 14 | 0.80 | 69.588 | +0.080 |
| 2 | 13 | 0.82 | 69.708 | -0.010 |
| 3 | 2 | 0.84 | 69.501 | +0.111 |
| 42 | 7 | 0.83 | 70.141 | -0.043 |

脑区骨干沿用 EfficientNetV2（Tan 与 Le，ICML 2021），195 维观测、加入残差的位置以及本次线性对照来自本项目。头部损失采用 Lin 等在 ICCV 2017 提出的 Focal Loss。[论文与归属](../../../REFERENCES.md) · [实现](../study.py) · [完整实验命令](../README.md) · [同种子比较和诊断](../RESULTS.md)
