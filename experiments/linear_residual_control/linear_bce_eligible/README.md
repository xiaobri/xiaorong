# linear_bce_eligible

在Train 清单中正、负样本均至少 50 个的采集组上，用无权重的 BCE-with-logits监督零初始化的 195→1 线性残差。锁定学习率为 0.0001。原六专家核心使用基线完整损失。

| seed | 轮次 | 阈值 | F1 | Δ baseline |
| --- | ---: | ---: | ---: | ---: |
| 0 | 1 | 0.81 | 69.161 | -0.660 |
| 1 | 2 | 0.77 | 69.094 | -0.414 |
| 2 | 1 | 0.84 | 69.140 | -0.578 |
| 3 | 2 | 0.74 | 68.997 | -0.393 |
| 42 | 5 | 0.46 | 68.832 | -1.352 |

脑区骨干沿用 EfficientNetV2（Tan 与 Le，ICML 2021），195 维观测、加入残差的位置以及本次线性对照来自本项目。头部使用标准 Bernoulli 对数损失；原核心的 Focal 沿用 Lin 等在 ICCV 2017 提出的目标。[论文与归属](../../../REFERENCES.md) · [实现](../study.py) · [完整实验命令](../README.md) · [同种子比较和诊断](../RESULTS.md)
