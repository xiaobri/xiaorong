# linear_focal_eligible

在Train 清单中正、负样本均至少 50 个的采集组上，用原项目 Focal（阳性 α=0.85，γ=2）监督零初始化的 195→1 线性残差。锁定学习率为 0.002。原六专家核心使用基线完整损失。

| seed | 轮次 | 阈值 | F1 | Δ baseline |
| --- | ---: | ---: | ---: | ---: |
| 0 | 3 | 0.58 | 71.159 | +1.338 |
| 1 | 7 | 0.78 | 71.219 | +1.711 |
| 2 | 3 | 0.45 | 70.901 | +1.182 |
| 3 | 3 | 0.77 | 70.986 | +1.596 |
| 42 | 10 | 0.59 | 70.809 | +0.625 |

脑区骨干沿用 EfficientNetV2（Tan 与 Le，ICML 2021），195 维观测、加入残差的位置以及本次线性对照来自本项目。头部损失采用 Lin 等在 ICCV 2017 提出的 Focal Loss。[论文与归属](../../../REFERENCES.md) · [实现](../study.py) · [完整实验命令](../README.md) · [同种子比较和诊断](../RESULTS.md)
