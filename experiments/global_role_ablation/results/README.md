使用锁定的 D、E 检查点和训练时各自选定的阈值，对全部 166,079 个原始 EEG 窗口再次前向。原始 EEG 重放的 E−D 五种子均值为 **−0.0015** 个百分点。十个检查点的阈值判定与首次验证累计相差 1 个（窗口，检查点）组合。[逐检查点原始重放计数](raw_de.csv)

## 执行与验证

- 实现固定在 PR #3 提交 `39314134a55d588ffb9c6e6f5953d392bd024751`。A–E 各跑五种子，每个种子重新初始化并训练 20 轮，每轮 20,000 次抽样，batch size 128，FP32，原 AdamW lr 0.0005。可选 E_mean 未纳入本次矩阵。
- 每个种子直接以原始 EEG、原批次次序和尾批形状执行五个冻结脑区专家。D 的原生训练前向和首轮验证产生 FP32 表示及 logits，各组共享这些冻结输出；每个模型独立计算全局专家、路由、扰动视图、损失及优化器更新。文件摘要、顺序、标签、冻结权重和清单均核对。
- 731,610 个训练窗口（阳性 190,413，阴性 541,197），验证窗口阳性 3,471、阴性 162,608。沿用原划分，训练与验证同路径重叠 0；目录推断有 3 个疑似重叠，患者独立性未核实。每组在同一验证集独立选择轮次及阈值，差值仅为描述性比较。
- PR 原始汇总器已逐轮核验 500 份预测、同种子初始化和抽样、模型配置、冻结区域预测以及混淆计数。原 PR 的 41 项回归测试及已有 13 项消融聚合核验通过。环境为 Python 3.10.20，PyTorch 2.4.0+cu121，torchvision 0.19.0+cu121，单个进程使用一张 RTX A6000。
